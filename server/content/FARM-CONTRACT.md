# Shared farm tutorial contract

Three independently authored articles must agree. Parent will review integration. These are educational Linux Docker examples, NOT the Windows learning app. Never deploy/download model/run Docker here.

Topology: browser -> Nginx gateway -> api1/api2 (stateless Express) -> inference A or inference B (one llama.cpp with the SAME Qwen GGUF/model identity on each). Express exclusively owns Postgres writes, auth, conversation authorization, turns, revisions, request IDs, provider policy and logs. Inference servers are stateless compute except ephemeral KV/prefix caches. Postgres is authoritative; cache warmth is optional.

Use Nginx least_conn (no sticky user hashing needed when Express is stateless); inference placement rendezvous hash(conversationId, serverId) over healthy same-model endpoints is an optional locality optimization, not correctness. Never hash raw bearer tokens into logging/affinity. Health failover can lose warmth. Never silently retry after emitted tokens; generation status must tell client partial/error/canceled.

First version: synchronous HTTP/SSE for interactive chat; no Kafka between Express and inference. Use bounded admission/timeout and explicit 429/503. Durable async jobs require a DB outbox/worker (or queue), leases, idempotency and per-conversation ordering. Do not imply event delivery alone gives exactly-once LLM execution.
